# O62 (archive: resolved or moot row)

**`[RESOLVED 2026-07-16 → see below; auto-fire wiring remains as O57]`** Mobile / Static / Free mode envelope defined + StaticMode retired**

The gate is closed:
the per-mode behaviour table is recorded as `core/mode/ModeEnvelope.kt` (the single source of truth) and the scattered binary `StaticMode` is gone.
`ModeProfile.kt` (O80, merged) decides *which* mode (DeviceState→UserMode); `ModeEnvelope.forMode(UserMode)` says what that mode *does*;
`ModeState` (StateFlow<UserMode>, app-impl `ModeStateManager`, sim/test `FixedModeState`) carries the live mode.
Scheduler/MessageStore/BleDiscoveryManager/MeshService all read the envelope — zero `if (isStatic)` branches remain. Test:
`core/…/mode/ModeEnvelopeTest.kt` (pins MOBILE=pre-O62 defaults, STATIC=old STATIC_BOOST/CACHE_BOOST constants, FREE⊇STATIC⊇MOBILE monotonicity).
**Recorded per-mode values (change a number here AND in ModeEnvelope.kt together):** (a) BLE scan/advertise power → MOBILE=LOW_POWER, STATIC=BALANCED, FREE=LOW_LATENCY (app maps to `ScanSettings`/`AdvertiseSettings`);
(b) Wi-Fi discovery cadence → 30s / 15s / 0=continuous; (c) gossip round interval → 15s / 10s / 5s;
(d) relay-batcher window → **uniform 100–500ms across all modes, deliberately NOT per-mode** (it's a timing-correlation defence per O27/§12;
weakening it because a device is plugged in is a privacy regression for a negligible latency win — RelayBatcher owns the constant);
(e) breadcrumb decay → 1h / 24h / 24h; (f) presence-beacon interval → null=mode-change-only / 5min / 2min;
(g) routing-weight multiplier → 1 / 3 / 10 (feeds O98 degree budget);
(h) storage-cache boost → 1 / 4 / 8 and scheduler boost → 1 / 3 / 6 (the h "storage fraction" is expressed as a MAX_MESSAGES/quantum multiplier, not an absolute quota — O23 owns absolute quotas).
**What remains (now purely O57, no longer gated):** the auto-fire wiring — BroadcastReceivers assembling a `DeviceState` on plug/screen/time changes and calling `ModeProfile.evaluate` → `ModeStateManager.setMode`, plus the G12 entry/exit self-presence pulses off the mode transition, plus a 3-way mode selector UI (today's Settings toggle is binary:
on→STATIC, off→MOBILE; FREE reachable only once auto-triggers land).
