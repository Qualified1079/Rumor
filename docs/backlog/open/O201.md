# O201

**`[DECISION+RESEARCH]`** Post-quantum hybrid for the DM / prekey path — harvest-now-decrypt-later under the decades-horizon threat model (filed 2026-07-30, privacy workshop)

O55's threat model is prolonged infrastructure collapse measured in months-to-years, and stored relay ciphertext (O38) can be harvested now and decrypted later.
Classical X25519 falls to a future quantum adversary;
a well-resourced party harvesting mesh traffic today could decrypt it once cryptographically-relevant quantum computers exist. Research:
a **hybrid KEM (X25519 + ML-KEM / Kyber, NIST FIPS 203)** for DM key agreement and the O38/O191 prekey path — *hybrid* so a flaw in the PQ scheme is never worse than classical-alone.
Costs:
much larger keys/ciphertexts (Kyber ~1 KB+ vs X25519's 32 B) — real on a bandwidth-starved mesh, so measure the wire-size hit and gate on whether the threat justifies it.
Not urgent, but the LONG horizon is exactly what makes it relevant here (unlike a chat app with a days-horizon threat model). Decision to record after research:
hybrid-now vs classical-with-a-migration-path. Use an audited PQ library, never hand-roll (prebuilt-first policy). See `docs/SECURITY_RESEARCH.md`.
Cross-ref O38, O191, O55, O45.
