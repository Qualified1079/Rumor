# O43

**`[TODO/SIM]`** Per-link heal-storm token bucket with traffic-class priority**

Round-robin scheduling guarantees fairness across senders but does not bound total throughput on partition heal.
When two large clusters merge, every node tries to flush its delta to every newly-reachable peer; aggregate is still N×peers messages.
Add per-outbound-link token bucket sized by traffic class: INFRASTRUCTURE / REALTIME pre-empt the bucket, BULK and reconciliation backlog share what's left.
Combined with O42's lazy-pull-by-default (small fingerprint exchange before pushing bodies), this addresses both bandwidth spikes and the DTN-documented "storage exhaustion during long partition" failure mode.
**Shares O32's prerequisite:** needs per-peer byte accounting, which only becomes meaningful once the scheduler/relay knows which peer each enqueue is targeted at.
The breadcrumb substrate (4010501) and offer-ordering bias (4010501) shipped without this refactor because they operate at the "offer batch presented to the session" layer;
O32 and O43 operate at the "decide which peer gets the next byte" layer below.
