# O181

**`[TODO/UI]`** `ThreadViewModel` re-decrypts the entire thread on every new message (audit #25)

Body reconstructed 2026-11-08 (the 2026-07-30 triage indexed this row but never wrote a body).
`ui/messages/ThreadViewModel.kt` maps the whole thread list through `toDisplay` → `decryptPayload` (:147) each time the thread Flow emits, so every new message re-runs X25519 + AES-GCM over every earlier DM in the thread — O(n) crypto per message, O(n²) over a conversation.
**Fix:** cache decrypted plaintext by message id (bounded, cleared on lock — plaintext must not outlive the identity, O115), decrypt only ids not already in it.
Cross-ref O115, O243.
