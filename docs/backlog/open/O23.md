**`[TODO/CODE]`** User-defined storage quota and plugin storage scopes**

Before first message, setup flow asks user to allocate a storage budget (e.g. "Reserve 2GB for Rumor").
All repos (messages, chunks, transfers, plugin data) share this budget. Plugins receive a scoped storage allocation within the global budget;
if a plugin needs more than its default slice it requests an increase via a system prompt the user approves — same pattern as Android runtime permissions.
File access for plugins follows the Storage Access Framework picker model (same as Signal):
plugin declares which file types it needs, user grants access to specific files or folders, not blanket storage.
