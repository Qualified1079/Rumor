**`[TODO/CODE]`** Plugin security tiers: DEX (read-only) vs APK (dangerous)**

DEX `.rumor` bundles run in Rumor's process and are limited to read-only / display-layer `PluginContext` APIs (observe incoming, register display filters, open settings panel).
Any plugin declaring dangerous capabilities (compose outbound messages, mutate contacts, register DM envelopes, open network connections) must ship as a bound-service APK running in its own isolated Android process with its own Android permission grants.
Loader enforces this: DEX plugins requesting dangerous APIs are rejected at load time.
User sees "this plugin requires installing a companion app" for APK-tier, which is natural friction proportional to actual risk.
Manifest capability list re-disclosed on plugin update if capabilities changed.
