**`[TODO/CODE]` `[DECISION]`** RBSR by-id requests bypass the per-peer routing filter for DMs

GossipSession serves any id a peer requests through GossipEngine.messagesByIds, which returns stored DMs without the engine's intendedPeers / breadcrumb filter (it does refuse BRIDGED as of 2026-11-11).
Above the RBSR threshold a peer can therefore pull routed DMs that the offer path would have withheld.
Decide whether that filter is a privacy boundary (then enforce it on the by-id path, which needs the peer id passed in) or a bandwidth optimisation (then say so in O58/O204).
The session's own backfill already excludes routed types.
