If A's beacon is stale only in B's view, A computes Host (sees itself FREE) and B computes Host (sees A MOBILE) — nobody joins, contradicting `PersistencePlanner.kt:23-24`'s "never conflicting roles".
`selfRole()` is recomputed from scratch every 12s, so a role flip tears down a group even when no link changed.
`PersistenceReconciler.forget()` has no callers (5th orphaned-method instance).
**Fix:** use the last-known mode for held links, and hold a role for N rounds before switching. Sim it first.
