**`[TODO/CODE]`** Reproducible-builds requirement for peer-distributed plugins**

F-Droid treats reproducibility as best-effort because they also do source review + host signing.
Rumor has neither — the bundle hash is the only identifier reviewers anchor to, and without reproducibility a signed review (O26) describes a black box that no other client can verify.
Mandatory for plugin bundles: manifest declares source URL + build command;
clients can optionally verify-by-building on install if a build environment is available; community attestation reviewers MUST verify before signing.
Without this, the peer-review system in O26 is theatre.
