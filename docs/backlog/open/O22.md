# O22

**`[PART]`** Native delayed / recurring message scheduling**

Reduces pressure on plugins needing outbound-message capability. UI:
compose a message, tap a clock icon, set send time or recurrence (hourly / daily / on next peer contact). Stored locally; `MeshService` fires them on schedule.
Covers the primary legitimate use case (status bots, scheduled announcements) without requiring a plugin that declares outbound-message capability.
**Merge note:** Room `ScheduledMessageDao/Entity/Adapter` + DI binding + `MessageScheduler` binding landed via archimedes — remainder is the `MeshService` polling loop + compose-screen UI (clock icon).
