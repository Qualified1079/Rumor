# O169

**`[TODO/CODE]`** Plugin coroutine scopes have no `CoroutineExceptionHandler` — a bridge collector crash is fatal to the whole process (filed 2026-07-30, audit #10)

`PluginRegistry.register()` (`PluginRegistry.kt:63`) builds each plugin's scope bare.
Both bridges launch their inbound/outbound collectors directly via `pluginScope.launch{}` rather than through the try/catch-wrapped `PluginRegistry` dispatch site (the one place O25 hardened), so those coroutines have no safety net — worse than the "plugin crash disables the plugin" guarantee O25 was built for.
Fix: install a `CoroutineExceptionHandler` on the plugin scope that routes an uncaught throw to O25's disable path. Cross-ref O25.
