**`[TODO/CODE]`** Nostr relay fallback when internet is reachable**

Bitchat-style:
when an internet connection appears (Wi-Fi, cellular), opportunistically forward messages to Nostr relays over Tor (or I2P), and ingest matching events back.
Extends Rumor's mesh-only reach to cross-region delivery — mesh in city A talks to mesh in city B via Nostr-over-Tor without either mesh having continuous internet.
Different threat model from the in-mesh case (relays are public, observers many), so it gets its own design pass before implementation. Concrete decisions owed:
which Nostr event kinds Rumor uses (custom NIP?), how userId↔npub maps, whether Rumor messages are carried as encrypted `_ext` blobs inside otherwise-standard events.
Tor integration via tor-android (Briar uses it) or Arti once mature. Cross-references O54 — Nostr is effectively a transport plugin.
