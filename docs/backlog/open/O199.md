# O199

**`[TODO/EMU]`** Lock & device-access privacy hardening (filed 2026-07-30, privacy workshop)

Optional hardening for a lost, seized, or borrowed device — reduces what a device out of the owner's hands exposes.
(1) **Passphrase-only lockdown mode** — disables biometric unlock and hides notification content until the passphrase is entered (a memorized secret is a stronger factor than biometric, which can be satisfied without the owner's cooperation);
mirrors Android's own Lockdown.
(2) **Panic action** (gesture / hardware combo) → instant lock, optionally to the O189 decoy profile and/or firing the O192 key-retirement trigger.
(3) **Wipe-on-N-failed-attempts.** (4) **FLAG_SECURE** so the unlocked screen isn't captured via screenshot/Recents (= O165).
(5) **Notification content control** (= O200).
**The strongest single mitigation is that little sensitive data EXISTS on the device:** ephemeral mode (O190) + disappearing DMs (O193) — anti-forensics by nonexistence, the O38 philosophy applied to the whole device.
Honest limit (O27): on-device deniability is never absolute; decoy + nonexistence are the best available posture, not a guarantee — state it plainly.
