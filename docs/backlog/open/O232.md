# O232

**`[PART]`** Send-side transfers never reach COMPLETE — outbound records and chunk BLOBs kept forever (filed 2026-11-06; the cancel-binding half closed as G67)

`core/transfer/TransferSender.kt`:
no ACK/receipt path sets COMPLETE for SENDING, so prune (terminal-only) keeps every outbound record and its chunk BLOBs forever;
ABANDONED doesn't free the outbound chunks either.
**Fix:** a sender-side terminal state — receipt-driven for a DM transfer (the receiver's COMPLETE could ride a small ACK), time-bounded for a broadcast one (no receiver set to wait for) — that releases chunks.
Also: the transfer prune has no caller at all (see O249).
