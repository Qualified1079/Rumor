**`[TODO/CODE]`** N-of-M co-signed updates for high-capability (APK-tier) plugins**

npm event-stream / Obsidian silent-update / VS Code `ahban.cychelloworld` post-mortems converge on this:
initial review doesn't catch a popular plugin's subsequent malicious update.
Single mitigation that has worked in the wild is Bitcoin-Core-style mandatory N-of-M signed releases.
For Rumor's APK-tier plugins (outbound messaging, contact mutation, DM-envelope registration, network access), require updates to be co-signed by ≥2 maintainer keys declared in the original manifest.
Single compromised key cannot ship a malicious update. Real friction proportional to capability — DEX-tier (read-only display) plugins keep single-sig updates.
