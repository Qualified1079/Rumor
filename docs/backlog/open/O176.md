# O176

**`[DONE 2026-08-03]`** `BreadcrumbCache.snapshot` is an unbounded in-memory map (filed 2026-07-30, audit #14)

**Fixed:** capped the in-memory snapshot at `SNAPSHOT_MAX_TARGETS=2048` (targetUserId is a sender → unbounded under a sybil sender-flood);
`trimSnapshot(keep)` cold-evicts arbitrary entries (safe — it's a cache; a miss falls back to the persistent `candidatePeers` or flood). Cross-ref O120, O177.
