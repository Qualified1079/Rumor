# O228

**`[DECISION + TODO/CODE]`** Screenshot blocking can be switched off by anyone holding the unlocked phone (filed 2026-10-11)

O165's FLAG_SECURE became a default-ON Settings switch (user request — some users want to screenshot their own threads).
Turning it OFF needs nothing, so someone with brief access to an unlocked phone can disable it silently;
afterwards passphrase entry and decrypted DM threads can be screen-recorded by malware or read from the Recents card, and the owner has no signal.
**Option:** require the passphrase to turn it off (turning on stays free); KDF off the main thread as in G56. Cost: one dialog. User's call.
