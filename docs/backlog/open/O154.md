# O154

**`[TODO/CODE+DECISION]`** No public/open-join *rooms*; keep ONE ungoverned text-only global *feed*, scaled by priority-weighting (NOT hard shards) — filed 2026-07-24, revised 2026-07-25

**Decision (user):** kill open-join **rooms** entirely — all *rooms* are invite-gated/governed (so all get O151 enforceable provenance bans;
a governed space should not be crawlable-open).
BUT keep **the feed** — the ungoverned, text-only, global broadcast stream (the O36 global-room-text-only surface + O71 nearby-broadcasts filter).
**The feed is NOT a room** (no membership, no authority, no invite);
ambient public broadcast, moderated only by *local* block/keyword-filter (O67/O78), never mesh-authority.
**Feed purpose is deliberately narrow (user 2026-07-25):** peer **discovery** + **ambient local conversation in non-flooded conditions**.
It is NOT a coherent 10k-person town square — at scale it degrades to noise, and that is *acceptable* because both jobs are inherently local.
So the feed needs graceful degradation, NOT a scaling solution.
**Scaling model — HARD SHARDS REJECTED (user 2026-07-25), replaced by priority-weighting over ONE undivided global:** the physics is real (a mesh can't carry ~10k posters to everyone), so *something* must decide each node's slice — but hard shards (`global 1/2/3` named tags you're "in") fragment the commons and violate the one-town-square model.
Instead: ONE global namespace; posts are *tagged* (topic/hashtag) but never *partitioned*;
each node relays+stores by a **priority function** ≈ `boosted-topics + recency + proximity/hops + a baseline floor for un-boosted global`.
Ample bandwidth (small mesh) → floor high → carry everything → true complete global;
constrained (10k) → each node keeps its prioritized, overlapping window — the commons is *weighted*, never *cut*.
"Subscribe to a topic" (O140) becomes "**boost** its priority," not "join a shard" — so there is nothing to hop between, and un-boosted global still trickles at the floor (you never miss it by focusing).
**Better fit with relay-never-filters than shards:** a node carries everything it has budget for *in ranked order* and drops only at the budget edge — it never categorically refuses a *class* of traffic (that would be the forbidden filter);
emergency/local-alert sits at the top of the floor, always carried.
This is the O23 eviction ranking + O43 relay-priority buckets + O58 proximity signals unified into one score.
**Honest limit:** priority does not repeal physics — at scale no node sees the *whole* global under any mechanism;
the achievable truth is "one global namespace, each node holds a prioritized window of it" (the most faithful approximation of the single square, better than shards because it never divides it).
A very-large *community* is then a **boosted topic on the one global**, not a shard — room and global are the same feed at different priority weights (folds O153/O155's "large → feed-shaped").
Sybil interaction analyzed in O135 (topic-flood sinks to the floor, identity-count irrelevant since caps are per-resource;
residual = passive-discovery noise, mitigated by proximity + active solicitation).
