# O88

**`[TODO/UI]`** In-thread plugin display widget hook**

A `@Composable PluginDisplay(message: RumorMessage)?` declared by plugins that want to render their own MessageType inline in `ThreadScreen`.
Falls back to default rendering (plain `[binary payload]` or hex-dump) if no plugin claims the type.
Required for any payment/attestation companion that wants to show structured content ("$5 sent", "credential verified") inside the chat thread rather than driving the user out to a separate app.
Lower priority than O87 because the companion can ship without it (separate-app UX is the v1 fallback). Filed by the O84 audit.
