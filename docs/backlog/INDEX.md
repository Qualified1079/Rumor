# Backlog index — one line per open row

Moved out of `CLAUDE.md` on 2026-11-10 so the index is no longer loaded into every session.
Grep this file for a topic or a row number; do not hand-edit the tables except to tick a box.

## Layout

| Where | What |
|---|---|
| `docs/backlog/INDEX.md` | this file: every open row, one line, grouped in tiers |
| `docs/backlog/open/O123.md` | full body of an open row: status, remaining work, invariants, cross-refs |
| `docs/backlog/done/G45.md` | a completed gap (was `docs/COMPLETED_GAPS.md`); don't load during normal work |
| `docs/backlog/archive/` | full tombstone records and shipped-substrate records of `[PART]` rows |
| `docs/DECISIONS.md`, `docs/UI_BACKLOG.md` | narrow recorded decisions; UI rows folded into O143 |

`python scripts/backlog.py show O123` prints a row's full text from whichever of these holds it.
**Read the body before believing a row's status** — titles go stale, and one session built against a row that had shipped months earlier.

## Filing and closing

Use `scripts/backlog.py` (it edits the index and the row files together); `BacklogConsistencyTest` fails the `:core` suite on drift.

- `next-id` — next free O / G number. Numbers are never reused.
- `file --tier N --tag TODO/CODE --title T --body B` — new row, slotted into the tier whose downstream-dependency weight matches.
- `close O123 --title T --notes N` — close as the next G; add `--remaining-title/--remaining-body` to close half a row.
- **Cheapest close:** tick the box (`| O123 [ ] |` → `| O123 [x] |`) and run `sweep` (`--dry-run` to preview, `--resolution "…"` optional).
- `check` — consistency check, including the `CLAUDE.md` size budget and over-long lines.

## Status tags

| Tag | Meaning |
|-----|---------|
| `[PART]` | Substrate shipped, follow-up specified in the body. |
| `[DECISION]` | Position recorded — no code to write. Exists to prevent the same conversation recurring. |
| `[TODO/CODE]` | Pure protocol or library work; JVM-testable; no special platform needed. |
| `[TODO/SIM]` | Implementation lands in `:core` or `:simulator`; validated by a simulator scenario. |
| `[TODO/UI]` | Compose UI surface; verify by eyeball on emulator. |
| `[TODO/EMU]` | Needs an Android emulator (Keystore, FLAG_SECURE, biometric prompt, Doze). |
| `[TODO/HW]` | Needs real hardware (a Pixel-class device for battery; a Meshtastic/MeshCore radio for bridge work). |
| `[STRUCT]` | Foundational/structural — cross-platform architecture correction (phone app + desktop app + USB-bootable node). Schedule ahead of feature work touching the same area; deferring one multiplies the cost of every later change in its area. |
