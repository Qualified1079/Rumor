**O93 same-LAN transport + O98 blind derived-SSID join + §5 startMesh reentrancy guard — 0.6.1-o93-lan (code-complete, field check pending)**

Three pieces, one flash. **(1) O93 LAN path:** `core/transport/lan/LanTransport.kt` — pure JVM (the :node target reuses it as-is):
JmDNS (`org.jmdns:jmdns:3.6.3`, new :core dep per the prebuild policy — never hand-roll mDNS) advertises `_rumor-gossip._tcp.local.` with a 16-hex userId-prefix service name (connection targeting only, NEVER identity — the MAC rule applies to mDNS names verbatim;
identity stays HELLO Ed25519), browses for peers, and runs the untouched `GossipSession` state machine over plain TCP (ephemeral server port carried in the mDNS record).
Per-peer 10s round loops, first-come-wins session claim, results emitted as `PeerExchangeResult(source=LAN)` (new `ExchangeSource.LAN`).
mDNS setup is best-effort — TCP server survives multicast-filtered environments.
`app/…/transport/lan/LanTransportManager.kt` brings it up exactly while STA-associated (a TRANSPORT_WIFI network callback supplies the interface IPv4) and holds a `MulticastLock` (new `CHANGE_WIFI_MULTICAST_STATE` permission — AOSP-safe, no GMS).
**LAN exchanges deliberately do NOT feed the O98 coordinator**:
the backbone planner realizes P2P groups, and planning links for LAN-reachable peers would make the radio fight the AP association this path exists for.
**(2) O98 scan-throttle fix (G38 known-limitation closed):** `joinBackboneGroup` no longer waits for the target SSID to appear in throttled scan results — credentials derive from the planned host's userId, so it joins *blind*;
blind joins are exempt from the 3-min SSID cooldown (both onFailure and watchdog paths — "not up yet" is their expected failure, and cooling would lock the client out right when the host arrives;
pacing stays with the bounded role-retry structure). Scan-visible joins and the leave-wrong-group gate (`verifyClientGroup`) keep ground-truth gating unchanged.
**(3) §5 fix:** `startMesh` now latches `meshStarted` (set only after the identity check so a locked start retries;
cleared in `stopMesh`) — foreground transitions no longer stack duplicate flow collectors / orphan transports. Tests:
`LanTransportLoopbackTest` (core — two transports on loopback, discovery injected via the internal `onPeerLocated` seam; the mDNS layer is hardware-verified).
