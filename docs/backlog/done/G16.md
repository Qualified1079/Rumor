# G16

**O18 transfer cancel + pause/resume API**

New `MessageType.TRANSFER_CANCEL` direct-routed message with `TransferCancel(transferId)` payload. `TransferSender` honors inbound cancel:
drops the transfer from cancelledByReceiver set, marks ABANDONED, skips further chunk-request responses.
`TransferAssembler` exposes `pause(id)` / `resume(id)` / `cancel(id)`: paused transfers drop chunks at ingest (watchdog keeps running);
cancel composes the outbound TRANSFER_CANCEL, drops local chunks, marks ABANDONED.
UI surface (per-transfer pause/resume/cancel buttons) deferred to next UX session. Commit `0ce61ab`.
