# G7

**CI + versionCode discipline (O10)**

`.github/workflows/ci.yml` runs unit tests + debug APK assemble on PRs to `main`.
`.github/workflows/release-check.yml` runs on `v*` tag pushes, parses `versionCode` from `app/build.gradle.kts` at the current tag and at the previous tag, fails the workflow if the new value is not strictly greater.
F-Droid and Play both reject non-monotonic uploads so catching it pre-release avoids a wasted submission.
Gradle wrapper (gradlew + gradle-wrapper.jar) committed at version 8.6 in `eb266e5` — contributors and CI now build against the pinned gradle.
