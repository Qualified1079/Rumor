# G63

**O159 transfer-layer test coverage, incl. making the NACK watchdog testable (2026-10-11)**

`TransferAssembler`/`TransferSender` had ZERO coverage despite being where O108/O109's resource-exhaustion hardening lives;
O158's chunk-BLOB leak was the proof that gap was live.
Three suites, all driven through real `SimTransport` with hostile input composed as genuinely signed messages (SIMULATOR_TESTING rule 1).
`TransferAssemblerHardeningTest`: O108 metadata plausibility, the O108 per-sender cap (8), chunk-index range, chunk-size bound, O100 per-chunk hash.
Every rejection paired with an accepted twin differing only in the field under test — the cap's control is a *different sender* still getting in, or the cap is a global DoS one sender can inflict.
`TransferNackWatchdogTest`:
the schedule (`nackInitialDelayMs`/`nackDelayCapMs`/`nackMaxRetries`), `clock` and `scope` are now constructor params with the shipped values as defaults (no call-site changes, `SystemClock.now()` → injected clock in all 5 places), so the real logic runs on a 40 ms schedule — stalled → ABANDONED + chunk rows released, windowed NACK first, **metadata with no chunk arms no watchdog** (O108 evidence-gating, and the control that makes the abandon mean "stalled" not "the clock ran"), progress refills the budget.
`TransferSenderTest`:
exact-index retransmit (a sender answering a NACK with the whole file hands the receiver an amplification lever), unknown-transfer ignored, receiver-cancel silences further NACKs with a pre-cancel NACK as the positive control.
**All 11 teeth-verified by breaking exactly one rule at a time and confirming only the matching test fails.** Two of these tests initially proved nothing and were caught by that check:
the plausibility test asserted before the liar was processed, and the sender test used a 40-byte payload — `Chunker` defaults to 60 KB chunks and `sendFile` takes no override, so it was a ONE-chunk transfer and a NACK for indices 1/3 was correctly ignored.
Use a 200 KB payload for multi-chunk transfer tests.
