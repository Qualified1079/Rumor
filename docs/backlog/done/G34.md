# G34

**O87 `PluginContext.signWithLocalKey`**

`PluginContext` interface adds `fun signWithLocalKey(bytes: ByteArray): ByteArray` with extensive contract docstring (hard rule:
plugins sign only their own bytes; documented but not enforced because a malicious plugin already has worse capabilities;
throws `IllegalStateException` on locked identity).
`PluginContextImpl.signWithLocalKey` in `:app/plugin/PluginRegistry.kt` calls `CryptoManager.sign(bytes, identity.privateKeyBytes)`.
`IdentityManager` was already a constructor param, so no plumbing was needed — just the 4 effective lines.
Hard prereq for O20 Keystore-backed signing now in place: when signing moves into the TEE, this is the only Kotlin-side call site that needs to change.
No new tests — surface is so directly mechanical that a Robolectric/mock-heavy test is disproportionate; G6 Koin DI verify catches wiring breakage.
Closes the first of two O84 audit follow-ups (O88 remains open — in-thread plugin display widget, lower priority because companion apps can ship without it).
