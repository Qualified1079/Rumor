# G53

**O89 Rooms write-authority enforcement (2026-10-10)**

`RoomPostingCertVerifier` had **zero production call sites**: `composeRoomMessage` attached no cert and `handleRoomMessage` performed no authority check.
Because an OPEN room's routing tag is a deterministic, keyless function of its public roomId, *any* client that could compute the tag could post into a "governed" room — governance was a UI label with nothing behind it.
**Now:** `composeRoomMessage(postingCert =)` stamps the cert pre-sign via `buildMessage` (same slot as O157's tag) and `GossipEngine.isAuthorizedToPost` gates the receive path after the tag match.
Seven checks in cost order: room requires a cert; cert present and well-formed; cert scoped to THIS room;
cert names THIS sender (else a cert observed on the wire could be replayed by anyone);
moderator signature + moderatorId↔pubkey binding (`RoomPostingCertVerifier`);
issuer is a moderator **right now** (so demotion takes effect without waiting for expiry); wall-clock inside the validity window.
**Fails CLOSED** for a governed room and **OPEN** only where there is nothing to enforce — no `RoomAuthorityProvider` wired, or a room declaring it needs no cert (the ungoverned feed, O154/O186).
New `GossipEngine.RoomAuthorityProvider` keeps `requiresPostingCert`/`isModerator` separate from `RoomSubscriptionProvider` because the real implementation needs the `RoomRepository` read that O187 still owes;
null = no enforcement.
Cert rides `_ext.pc`, **bound into the signed transcript** — its moderator signature already protects its contents, but binding stops a relay STRIPPING it and making every honest downstream node reject a legitimate post (one relay amplified into mesh-wide censorship).
**`RoomPostingAuthorityTest` (8)** drives the real `onExchange` path: valid cert accepted;
no cert / non-mod issuer / cert naming another user / cert for another room / expired / not-yet-valid all refused;
plus the load-bearing control that with no provider an uncertified post IS delivered — which is what proves the refusals come from the authority check and not from room delivery being broken.
**Teeth-checked:** removing the one enforcement line fails exactly the 6 refusal tests and leaves the 2 delivery tests passing.
