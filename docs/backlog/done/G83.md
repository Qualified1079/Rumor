# G83

**CRITICAL: the engine graph is hand-assembled in three hosts (AppModule, SimNode, :node) and has drifted; build it once in :core (filed 2026-11-08)**

Closed via tick-box sweep 2026-11-08: core/runtime/MeshGraph builds the engine graph once from a MeshRepositories bundle + host hooks;
AppModule, SimNode and :node construct only a MeshGraph (rules in CLAUDE.md Host wiring). Fixed the four drifts. Found + fixed a latent lifecycle bug:
BlockManager/TopologyTracker/BreadcrumbCache each ran on a self-made never-cancelled scope (BlockManager a `while(true)` prune loop), and MeshGraph wasn't passing the transfer classes a scope either — so no graph could ever be stopped, and once a lambda pinned the graph the sim suite OOM'd.
All five now take a child of the graph's scope; teeth-checked (sweep OOMs again with BlockManager's scope un-injected).
Commits 1fb4086 + the scope commit after it.. Last row body:
Every host builds GossipEngine + MessageStore + Scheduler + BlockManager + trackers + transfer + rooms by hand, so every new engine dependency must be wired three times, and nothing fails when one host forgets.
Drift found 2026-11-08: (1) BlockManager gets localUserId (the cannot-self-block invariant) only in AppModule; SimNode and :node build it without.
(2) MessageStore/Scheduler get modeState only on Android, so mode-driven eviction and quantum boosts never run in sim or :node.
(3) the RoomSubscriptionProvider is two inline copies (AppModule, SimNode) and missing in :node.
(4) RoomRepository + RoomAuthorityResolver are wired only in AppModule (O187), so sim and :node nodes never apply room lifecycle or enforce O89. Consequence:
a simulator or :node result says nothing about the phone graph it is meant to stand for, and the desktop node (O106) ships a different engine from the phone.
Fix: one :core class builds the graph from a repository bundle + host hooks (identity, mode, inbox filter, clock, scope, relay windows);
hosts supply only storage and platform hooks and never call the engine-graph constructors themselves. The rule goes in CLAUDE.md's DI section.
Cross-refs O106, O107, O187, O185.
