# G51

**O123 plugin disable-boundary race (2026-07-23; extends O25)**

`PluginRegistry.onMessageReceived` iterated the `CopyOnWriteArrayList` snapshot and could invoke a plugin that `unregister()` had concurrently torn down (scope cancelled, `onDetach()` run) — bounded blast radius (per-plugin try/catch swallowed the throw) but the object was called on torn-down state.
Fix: each plugin held in a `PluginHolder` with a `@Volatile alive` flag;
`unregister()` clears it FIRST (before scope cancel + onDetach), the dispatch loop skips any non-alive holder.
`PluginDisableBoundaryTest` source-guards both halves (full live test would be ~18-param GossipEngine scaffolding for a flag guard — used the SourceInvariantTest idiom instead).
The auto-disable-on-crash remainder of O25 is still open.
