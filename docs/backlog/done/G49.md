# G49

**O109 windowed chunk requests (2026-07-23)**

`Chunker.missingIndicesWindowed(received, totalChunks, window=1024)` replaces the eager `(0 until totalChunks).filter{}` — memory + NACK-frame size are O(window) regardless of a lying totalChunks (verified:
`totalChunks=Int.MAX_VALUE` returns exactly the first `window` indices, no giant allocation). The watchdog NACKs one window;
the next window is requested naturally as chunks land. Watchdog rewritten to a progress-aware budget:
retries refill while chunk count climbs, only a genuinely stalled transfer burns down to abandonment (a large multi-window transfer no longer dies at 5 fixed retries).
`ChunkerTest` windowed battery (window cap, front-fill, near-end short return).
