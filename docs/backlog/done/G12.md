**O30 + O57 self-presence (wire pieces) + mode-change pulses**

New `MessageType.SELF_PRESENCE` carrying `SelfPresencePayload(mode, authorizedAtMs, recentlyExchangedWith, _ext)`.
`composeSelfPresence(mode, recentlyExchangedWith)` on `GossipEngine`.
Same primitive serves entry pulse (Static/Free up) and exit pulse (back to Mobile) — exit is just a fresh beacon with mode=MOBILE, not an amendment.
Routes through trafficClass (INFRASTRUCTURE), relay (broadcast-style), clampTtl (MAX_BROADCAST_HOPS).
Auto-fire-on-mode-change wiring (plug/unplug events, screen on/off, manual toggle) deferred to next emulator session — orchestrator's job, depends on Android platform APIs.
