# G13

**O17 BRIDGE_VOUCHED**

New `TrustLevel.BRIDGE_VOUCHED` (between VERIFIED and BRIDGED) + `MessageType.BRIDGE_VOUCHED` + `BridgeVouchedPayload` carrying origin network/sender + foreign-network signature + payload.
`GossipEngine.composeBridgeVouched` wraps foreign content in a Rumor-signed envelope;
receivers verify the outer Ed25519 like any other signed message and relay normally.
Distinct from BRIDGED in that it propagates beyond direct peers — Charlie three hops away in the Rumor mesh now sees Bob's Meshtastic message.
Anti-laundering preserved: outer senderId IS the bridge's userId; bridge cannot claim someone else originated content.
Per-bridge trust toggles for receivers (UI) deferred. Commit `260c041`.
