# G5

**Pluggable `DmEnvelope` framework (O5a)**

`core/plugin/{DmEnvelope,DmEnvelopeRegistry}.kt` + three new `PluginContext` methods (`registerDmEnvelope`, `injectBridgedDm`, `observeOutboundBridgedDm`).
`GossipEngine.composeDirect` consults the registry by recipient prefix;
if a match is found, the envelope's `encrypt()` runs and the raw ciphertext is emitted on `outboundBridgedDm` for the bridge plugin to forward (the message is NOT enqueued in the gossip scheduler — bridged recipients aren't reachable via Rumor peers).
`GossipEngine.injectBridgedDm` enforces all six O5a security constraints:
derives the envelope by sender-prefix locally (not from wire-asserted `envelopeId`), drops on derived-vs-asserted mismatch, sets `BRIDGE_UNSIGNED` → `LOCAL_BRIDGE` → `TrustLevel.BRIDGED` (never re-relayed).
`PluginRegistry.unregister` calls `unregisterAllEnvelopes()` atomically *before* `onDetach`. Tests: `DmEnvelopeRegistryTest`.
