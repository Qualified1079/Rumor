# G20

**DM crypto fixed — first successful two-device DM (O91 port)**

Two stacked bugs meant no DM had ever worked on-device:
(1) `deriveAesKey` used `PBEKeySpec(null, secret+salt, …)` — Android BC throws "password empty", crashing `composeDirect` at send time;
replaced with HKDF-extract (`HMAC-SHA256(salt, secret)`).
(2) Ed25519 identity keys were fed raw into `x25519Agreement` — even without the crash both sides derive mismatched secrets.
Ported `Ed25519ToX25519` (RFC 7748 clamp + Edwards→Montgomery birational map) from the practical-archimedes branch (c44087e/31bd490, adapted from its KMP layout):
`composeDirect` converts the recipient pubkey, `ThreadViewModel.decryptPayload` converts the local seed (zeroed in `finally`).
`Ed25519DmRoundtripTest` pins both the shared-secret match and full encrypt/decrypt. Wire-format break vs. old builds is moot — the old path crashed.
Verified bidirectionally on the two test phones.
