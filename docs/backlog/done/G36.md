# G36

**O84 crypto-primitives audit**

`docs/CRYPTO_PRIMITIVES_AUDIT.md` walks a hypothetical Cashu-on-Rumor companion against today's `PluginContext` surface. Eight capabilities surveyed;
six are available today via G5 DmEnvelope + observeIncoming + sendMessage + content-agnostic relay. Two gaps filed as follow-ups:
**O87** (`PluginContext.signWithLocalKey`) and **O88** (in-thread plugin display widget hook).
The earlier "plugin-to-plugin secure channel" concern is rejected as not needed — intra-device IPC is the OS's job (bound-service for APK-tier, shared host storage for in-process), not a Rumor crypto primitive.
Confirms O86 architectural decision (crypto-as-payments stays out of core) is implementable as separate companion app today, modulo O87.
