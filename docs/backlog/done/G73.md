OPEN-room routing tag now bound into the signed transcript.
**Resolution:** `MessageStore.signableBytes` appends the length-framed `_ext.rt` value when `type == ROOM_MESSAGE` (gated on type — broadcast/DM transcripts stay byte-identical, so no wire regression and no domain-tag bump;
`type.name` is itself framed, so cross-type confusion is impossible);
`GossipEngine.buildMessage` gained a `roomRoutingTag` param and stamps `_ext.rt` BEFORE signing (was stamped post-sign).
A keyless retag of a validly-signed OPEN room message now invalidates the Ed25519 signature and is dropped at the verify gate — not merely unmatched.
The ENCRYPTED path signs the tag too (belt-and-suspenders atop the envelope's internal AEAD binding). Honest multi-hop unaffected:
`decrementHops` preserves `_ext`, HLC folds post-verify. Tests:
`RoomRetagForgeryTest` (sim, valid retag roomA→roomB dropped, honest roomB post delivered as discrimination control);
`RoomMessageMalformedTagTest` third assertion flipped (tampered tag now dropped-not-stored).
Docstring in `RoomRoutingTagExt.kt` corrected (its old "tampering achieves nothing useful" claim was the false premise this closes). Original finding below.
— `core/wire/RoomRoutingTagExt.kt:11-15` + `GossipEngine.kt:715-761` (`composeRoomMessage`) + `:1135-1152` (`handleRoomMessage`).
The routing tag lives in `_ext.rt`, explicitly NOT covered by the Ed25519 signature;
`RoomRoutingTag.openRoomTag(roomId)` is a pure public function (no secret needed for any roomId).
The OPEN compose path puts no room-identifying data anywhere in the signed transcript (`payload.content` is raw text). So:
take any validly-signed OPEN `ROOM_MESSAGE` (the attacker's own or merely observed), overwrite `_ext.rt` with `openRoomTag(otherRoomId)`, rebroadcast — signature still verifies (doesn't cover `_ext`), `RoomTagMatcher.match` matches on tag bytes alone, `handleRoomMessage` delivers unconditionally.
Alice's Room-A content displays to every Room-B subscriber, attributed to Alice, attacker needs no key.
Contradicts the file's own "tag tampering achieves nothing useful" claim (only true for a bogus tag, not a valid tag borrowed from elsewhere). Fix:
bind the resolved room into the SIGNED transcript — an O89 posting-cert alone does NOT stop post-signing retagging. Same root class as O156. Cross-ref O79, O89.
