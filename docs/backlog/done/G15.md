# G15

**O22 native scheduled / recurring messages**

`core/model/ScheduledMessage`, `core/data/ScheduledMessageRepository`, `core/scheduling/MessageScheduler`.
Polls `dueAt(now)` on a configurable tick, fires through existing `composeBroadcast`/`composeDirect`, advances or deletes the schedule.
One-shot, finite recurrence, and unlimited recurrence supported.
Burst-suppression on long-paused devices skips past-due intervals so a phone that resumes after hours doesn't fire a backlog.
`InMemoryScheduledMessageRepository` for simulator; Room adapter deferred to next Android session. Commit `74245a5`.
