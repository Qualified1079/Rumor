# G31

**O85 two-tier dedup (Tier 0 exact + Tier 1 bloom)**

`DuplicateFilter` now holds Tier 0 (LinkedHashMap LRU, 200k entries default) plus Tier 1 (BloomFilterData bloom, 1M slots at 0.1% FP, ~1.8 MB).
On lookup, Tier 0 exact check (with LRU-bump on hit) → Tier 1 bloom check on miss → genuine novel only if both miss.
Tier 0 eviction pushes the evicted id into Tier 1 via the `removeEldestEntry` hook.
Effective dedup memory grows from "last 200k seen" to "essentially every id ever seen for the process lifetime" at the small FP cost;
gossip/RBSR exchange catches the rare FP (one-exchange-period of latency). `longTailCapacity = 0` disables Tier 1 for MCU-class targets per O75.
Test coverage in `core/src/commonTest/.../TwoTierDuplicateFilterTest`.
